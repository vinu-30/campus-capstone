# Campus Capstone Project Team Matchmaker & Skill-Gap Auditor

The current version is a React + Bootstrap 5 dashboard with dummy data only. The backend MVC folders are ready, but no backend or database is connected yet.

## Run the dashboard

```bash
cd campus-capstone/frontend
npm install
npm run dev
```

Vite will show a local URL to open in your browser.
